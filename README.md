# ecommerce-user-segmentation
# 基于RFM-I模型的电商用户价值分层分析

个人项目 | Python (Pandas, NumPy, Matplotlib) | 数据来源：Kaggle公开数据集

## 项目简介

电商场景下传统RFM模型存在局限——无法识别"高浏览低消费"的潜力用户群体，
也未考虑用户购买力背景差异。本项目基于Kaggle公开数据集（1,000条用户消费
与行为记录），设计并验证了一套改良的RFM-I用户价值分层模型，在传统R/F/M
基础上引入行为意向度(I-Score)指标，识别高价值/高潜力用户群体，为精准营销
提供分层依据。

## 数据说明

- 数据集：Kaggle公开数据集（合成/模拟数据，非真实企业数据）
- 规模：1,000条用户记录，14个字段，0缺失值
- 关键字段：Last_Login_Days_Ago（对应R）、Purchase_Frequency（对应F）、
  Total_Spending（对应M）、Time_Spent_on_Site_Minutes / Pages_Viewed（对应I-Score）、
  Income（收入分层参考）

## 方法与分析过程

**1. 数据探索**
- 完成缺失值、异常值检查
- 相关性分析发现各变量间相关系数普遍<0.1（近似独立），
  据此判断该数据集不适合用相关性驱动权重设计

**2. R/F/M权重设定**
- 采用业务优先级设定：R=0.2, F=0.3, M=0.5（消费金额贡献优先级最高）

**3. I-Score（意向度）指标构建与验证**
- 由浏览时长(Time_Spent_on_Site_Minutes)与浏览页数(Pages_Viewed)标准化加权构成
- 对权重组合（0.5:0.5 / 0.7:0.3 / 0.3:0.7）做敏感性测试，
  对比各分组的购买频率、消费额差异
- 验证发现：各权重方案下分组差异均不显著，判断该数据集中行为指标
  与消费结果无强关联，故采用等权重(0.5:0.5)方案，理由是不引入无依据的主观偏向

**4. 用户分层与可视化**
- 基于加权综合得分完成15类用户分层
- 输出分层分布图、各群体RFM-I雷达画像图

## 关键发现与反思

- 原始15类分层中低样本量群体占比过高（如核心VIP仅2.3%，纠结土豪仅0.6%），
  可操作性存疑，建议后续合并精简分层以提升运营可执行性
- I-Score权重调整对购买频率/消费额的区分度影响有限，反映出该合成数据集
  变量间关联较弱的局限性
